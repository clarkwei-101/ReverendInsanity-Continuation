# 蛊真人续写

《蛊真人》同人续写项目。完整收录正文 225 章、大纲与世界观设定知识库。

## 目录结构

| 目录 | 内容 |
|------|------|
| `正文/` | 章节正文，`.md`（Markdown 源文件）与 `.docx`（Word 成稿）双格式 |
| `大纲/` | 总纲、全卷详细大纲、五个分卷章纲（覆盖第 1–200 章） |
| `知识库/` | 世界观设定、人物档案、蛊虫图谱、势力格局、文风指南等参考文档 |

## 正文进度

- 编号范围：第 0001 章 – 第 0225 章
- 第 1–11 章：仅有 `.docx`
- 第 12–200 章：`.md` 与 `.docx` 双格式齐全
- 第 201–225 章：仅有 `.md`
- 少数章号存在两个不同版本（如第 93 章的「古月方正的牺牲」与「重练永生蛊」），均为保留的独立草稿，未做取舍

## 说明

- `知识库/` 收录的是本项目自行整理的设定笔记与考据文档。
- 同人续写作品，版权及原著设定归原作者所有，仅供学习交流。
