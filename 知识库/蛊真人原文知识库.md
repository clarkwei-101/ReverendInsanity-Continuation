# 蛊真人续作知识库：原著核心设定

> 本文件为蛊真人续写的核心依据，所有设定均来源于原著。
> 续写必须严格遵循本文件，不得自相矛盾。

---

## 一、世界观基础

### 1.1 核心设定
- **世界名称**：蛊世界（五域两天）
- **核心法则**：人是万物之灵，蛊是天地真精
- **修行媒介**：蛊虫（蛊师→蛊仙→九转蛊尊）
- **力量来源**：蛊虫、空窍/仙窍、道痕

### 1.2 五域两天

| 地域 | 特色 | 代表势力 |
|------|------|---------|
| 中洲 | 门派制度，十大古派，人族霸权 | 天庭、灵缘斋、古魂门 |
| 北原 | 草原，黄金家族，男尊女卑 | 长生天、巨阳仙尊 |
| 南疆 | 山丘隐修，土道道痕深厚 | 多隐修蛊仙 |
| 西漠 | 沙漠绿洲，炎道风道 | 蛊修性格谨慎 |
| 东海 | 资源最丰，水道蛊修 | 鲛族，排外弱 |
| 幽天 | 两天合并后，幽魂魔尊为王 | 幽魂魔尊 |

### 1.3 天庭
- **性质**：太古白天洞天，天庭吞并大量太古九天碎片，是原本太古九天最大的余孽
- **核心加持**：大量智道道痕，置身其中者战力暴涨
- **三代仙王**：元始仙尊（第一代）、星宿仙尊（重生于当世）、历代天庭成员
- **仙墓**：储存天庭蛊仙，耗尽后可重生
- **当前状态**：被方源气功果大爆炸摧毁，元气大伤

## 二、境界体系

### 2.1 蛊师阶段（一转～五转）

| 境界 | 真元等级 | 说明 |
|------|---------|------|
| 一转 | 青铜 | 入门 |
| 二转 | 赤铁 | 小成 |
| 三转 | 白银 | 中成 |
| 四转 | 黄金 | 大成 |
| 五转 | 紫晶 | 巅峰 |

- 每转分：初阶、中阶、高阶、巅峰四小境界
- 相邻大境界真元质量相差十倍

### 2.2 蛊仙阶段（六转及以上）

- **空窍升级为仙窍/福地**
- 六转福地分：小、中、上三等
- 灾劫体系：六转十年一地灾、百年一天劫；七转加入浩劫；八转加入万劫
- 相邻大境界仙元质量相差百倍

### 2.3 九转蛊尊

**突破九转需满足四条件**：
1. 仙窍产出黄杏仙元
2. 道痕三十万规模
3. 主修流派无上大宗师境界
4. 突破天道封锁

**当前九转尊者（原著结束时）**：
- **方源（炼天魔尊）**：炼道成尊，九转蛊仙
- **星宿仙尊**：智道第一，天庭之主
- **巨阳仙尊**：金道，气运一道，北原霸主
- **幽魂魔尊**：魂道，无神智，两天合并后幽天之主
- **元始仙尊**：气道，正在复活（被方源炸断）

## 三、蛊虫体系

### 3.1 九转蛊虫

| 蛊名 | 流派 | 功能 |
|------|------|------|
| 春秋蝉 | 宙道 | 逆转光阴，重生回到过去 |
| 智慧蛊 | 智道 | 大幅提升推算能力 |
| 命运蛊 | 命运道 | 操控命运（已被粉碎） |
| 爱情蛊 | 特殊 | 九转，威能全面，几乎无所不能，但极难炼化 |
| 至尊仙胎蛊 | 核心 | 转化为至尊仙体 |
| 气功果 | 气道 | 用于复活 |
| 永生蛊 | 炼道 | 方源终极目标 |

### 3.2 蛊虫炼制规则
- 炼道尊者可炼制九转蛊虫
- 气功果复活本质 = 炼道炼制身躯与魂魄
- 方源精通炼道，可对分身进行提前处理

### 3.3 仙蛊屋
- 八转仙蛊屋：诛魔榜（古月方正掌）、星散营、细柳营等
- 中洲十大古派各有仙蛊屋镇压底蕴
- 尊者级别交战中，仙蛊屋渺小如蚊虫

## 六、原著最终章剧情（起点）

**第368节：方源、巨阳战星宿**（epub section 2347）

### 战场态势
- 方源（炼天魔尊）+ 巨阳仙尊 联手进攻天庭
- 星宿仙尊身在天庭，受海量智道道痕加持，以一敌二
- 星宿仙尊已用星雾暂时困住幽魂魔尊
- 幽魂魔尊无神智，只有兽性（除非九转火蛊发动）

### 星宿仙尊战力分析
- 在天庭中受到海量智道道痕加持，战力暴涨
- 目前以星雾困住幽魂魔尊，同时压制方源、巨阳
- 为保护气功果核，承受气爆绝大部分威能，已受伤
- 元始仙尊复活被中断，气功果核残存

### 方源已知弱点
- 巨阳仙尊目标是毁气功果核，非灭天庭
- 星宿仙尊在天庭战力最强，硬拼不智
- 需利用天庭智道道痕的逆向之法

### 赵怜云心思
- 持有爱情蛊（九转）
- 马鸿运魂魄在方源手中
- 欲借爱情蛊从方源仙窍中盗取马鸿运魂魄
- 等待方源最弱势时动手

### 古月方正心思
- 与方源有南疆旧识
- 身为天庭成员，立场对立
- 掌握画道，战力暴涨

## 七、续写必须遵循的铁律

### 7.1 方源角色铁律
1. 永生是唯一目标，所有手段皆可牺牲
2. 主动出击，不等死，不犹豫
3. 对盟友算计无情，对敌人斩草除根
4. 说话简短有力，绝不解释自己的计谋
5. **禁止**：表现同情心、犹豫、对弱者伸出援手（除非有利可图）

### 7.2 蛊世界物理铁律
1. 九转为尊，实力鸿沟不可跨越
2. 蛊仙需渡灾劫（六转十年地灾百年天劫）
3. 尊者级交手余波可灭蛊仙
4. 天庭中星宿受智道道痕加持，战力超越平常
5. 蛊虫有流派之分，不可混用
6. 炼道可炼制蛊虫、处理分身

### 7.3 文风铁律
1. 战斗描写：具体蛊虫名称、杀招名称、因果逻辑清晰
2. 内心描写：冷静算计，不煽情
3. 对话：简短精准，不废话
4. 情节节奏：铺垫→阴谋→反转→代价
5. **禁止**：系统流提示音、穿越者内心独白、轻松幽默
