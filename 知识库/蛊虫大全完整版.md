#### 至尊仙胎蛊

| 项目 | 内容 |
|------|------|
| **流派** | 核心 |
| **等级** | 九转 |
| **功能** | 将蛊仙转化为至尊仙体 |
| **当前持有者** | 方源（已使用） |
| **代价** | 必须每隔一段时间吞并与蛊仙修为相同的仙窍 |

> "方源如今已是九转，需吞并九转仙窍。这是至尊仙体最大的隐患。"
> —— 蛊真人原著

**永生蛊的副作用（续写新设定）**：
- 服下后，情感开始剥落。先是厌恶感，接着是惊讶感，最后是共情
- 三百年后，情感彻底消散，变成一尊真正的傀儡
- 削去一成威能，情感回来一成（反哺蛊的原理）

## 六、蛊虫炼制规则

### 6.1 炼道奥秘

**方源是炼道尊者**：
- 可炼制九转蛊虫
- 气功果复活本质 = 炼道炼制身躯与魂魄
- 方源可对分身进行提前处理（植入炼道手段）

**分身处理**：
- 方源可将分身（如气海老祖）作为"仙材"处理
- 可在其中植入炼道手段，旁人难以察觉
- 这是方源算计星宿仙尊的核心手段

### 6.2 至尊仙体的代价

- 必须每隔一段时间吞并与蛊仙修为相同的仙窍
- 方源如今已是九转，需吞并九转仙窍
- 这是至尊仙体最大的隐患

## 八、续写中的蛊虫使用原则

1. **蛊虫必须名实相符**：不能凭空创造蛊虫，必须基于已有设定
2. **流派不能混淆**：智道蛊虫不能有炼道效果
3. **等级决定威力**：九转压制八转，八转压制七转
4. **代价必须明确**：每使用强蛊都有代价
5. **新蛊要有来源**：如方源炼制新蛊，必须描写炼制过程
